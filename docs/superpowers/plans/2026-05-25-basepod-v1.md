# BasePod v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build BasePod v1 per `docs/superpowers/specs/2026-05-25-basepod-design.md` — CapRover-like PaaS for macOS using Podman + Caddy, Go backend, Vue 3 frontend.

**Architecture:** Single `basepod-server` Go binary embedding Vue SPA; talks to podman REST socket inside `podman machine`; controls a Caddy container via admin API. SQLite (sqlc + goose) for state. Separate `basepod` CLI hits the same `/api/v1` HTTP+SSE API.

**Tech Stack:** Go 1.26, chi router, sqlc, goose, modernc.org/sqlite, go-keyring, cobra (CLI), Vue 3 + Vite + TS + Pinia + Nuxt UI, Caddy 2, Podman 5.
