## basepod login

Log in to a BasePod server and save the resulting token

### Synopsis

Prompts for the server URL, username, and password, then issues a long-lived
API token and writes it to ~/.basepod/config.yaml. Subsequent commands use the
saved token.

```
basepod login [flags]
```

### Examples

```
  basepod login
  basepod login --server http://localhost:8080
  basepod login --server https://bp.example.com
```
